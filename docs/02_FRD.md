# FRD — 현장별 공정·기성 대시보드

## 한눈에 보기

- 화면 4개(현황 요약·현장별 비교표·자료 가져오기·AI에게 묻기)에서 무엇을 누르면 무엇이 일어나는지 기능 16개로 정리했습니다.
- 월·지역·공사 유형·현장 필터 하나가 숫자·차트·비교표·CSV·AI 범위를 함께 바꿉니다.
- 누적기성액(월말까지 쌓인 금액)과 당월기성액(그 달에 늘어난 금액 = 이번 달 누적 − 바로 전달 누적)을 따로 계산하고, 첫 달은 "계산 불가"로 둡니다.
- 오류가 나면 지금 자료는 그대로 두고, 어디가 문제인지 알려 줍니다. AI가 실패해도 대시보드와 CSV는 계속 씁니다.
- 시안(`design/`)은 배치와 분위기만 따르고, 시안 안의 예시 숫자·현장명·자료에 없는 항목은 쓰지 않습니다(맨 아래 부록 B).

## 4. 계산 규칙 표

근거: `data/데이터설명.md`와 `data/검산표.md`를 그대로 따릅니다. 계산은 프로그램이 하고 원본에 결과를 저장하지 않습니다. 모든 계산은 반올림하지 않은 값으로 하고, 화면·CSV에 보여 주기 직전에 한 번만 소수 첫째 자리로 반올림합니다(0.05는 올림). 반올림된 값을 다시 계산에 쓰지 않습니다.

| 번호 | 항목 | 계산 방법 | 예시 (검산표 숫자) |
|---|---|---|---|
| R-01 | 필터 범위 | 선택한 지역·공사 유형·현장에 속한 현장의 선택 월 행만 사용합니다. 추이는 같은 현장으로 시작 월~선택 월을 매월 따로 집계합니다. | 9월 인천·공동주택 → A·G 2곳. 계약금액 86,400 + 98,700 = 185,100. |
