# 개발 계획 — 현장별 공정·기성 대시보드

## 한눈에 보기

- EPIC(큰 작업 묶음) 3개, Story(작은 작업) 12개입니다. 실습조건의 "EPIC 3개 이하, Story 15개 미만"을 지킵니다.
- 순서는 ① 자료 가져오기·필터·현황·추이 → ② 점검 현장·기록 펼침·CSV → ③ 근거를 보여 주는 AI 질의입니다.
- EPIC마다 자동 검사를 돌린 뒤, 브라우저에서 확인할 행동과 보여야 할 결과를 하나씩 알려 드립니다.
- 학습자가 확인했다고 답하기 전에는 완료로 표시하지 않습니다.
- GitHub 저장과 Vercel 배포는 Story가 아니며, 각각 사용자가 별도로 요청한 뒤에만 진행합니다.

## 사용자가 별도로 요청한 뒤 진행하는 단계

아래 둘은 Story도 완료 조건도 아니며, 어떤 구현·검사 작업에도 묶지 않습니다. "구현 완료", "확인했어요", "다음으로", "알아서 해 주세요"만으로는 시작하지 않습니다.

| 단계 | 시작 조건 |
|---|---|
| GitHub 저장 | 사용자가 저장소 주소를 지정하고 "이 저장소에 올려 줘"처럼 명시적으로 요청한 경우에만, 그 범위에서 진행합니다. Vercel 배포를 포함하지 않습니다. |
| Vercel 배포 (STEP 11) | 사용자가 직접 진행하거나, 배포할 프로젝트·저장소를 정해 별도로 요청한 경우에만 진행합니다. |
